# مخطط الصحة المدرسية

تطبيق ويب عربي (RTL) في ملف واحد لتخطيط ومتابعة مهام الصحة المدرسية اليومية في:

- مدرسة أبو الدرداء للتعليم الأساسي
- مدرسة الإمام سيف بن سلطان للبنين

## المزايا

- **التبديل بين المدرستين** وحفظ بيانات كل مدرسة وكل يوم بشكل مستقل في المتصفح (LocalStorage).
- **شريط التاريخ**: أزرار سريعة (اليوم / الغد)، وأسهم لليوم السابق والتالي، واختيار أي تاريخ.
- **تقسيم اليوم**: الدوام المدرسي (07:10 ص – 01:30 م) وما بعد الدوام (01:30 م – نهاية اليوم). عند إدخال وقت المهمة تُحدَّد الفترة تلقائياً.
- **إضافة سريعة**:
  - محاضرة توعوية (اختيار صف من الخامس إلى الثاني عشر + عنوان المحاضرة)
  - تفعيل يوم عالمي في الإذاعة (عنوان المناسبة)
  - الفحص الشامل (اختيار أكثر من صف معاً)
  - المشاريع الصحية (مشروع تعزيز صحة الفم والأسنان، مشروع وزنك دليل صحتك، أو اسم آخر)
  - التحصينات واللقاحات
  - تنظيم غرفة الصحة المدرسية
  - مهمة مخصصة
- **تعديل أي مهمة** (النص، التصنيف، الصف، الفترة، الوقت، الملاحظات)، وتبديل حالتها بين **مكتملة / قيد التنفيذ**، وحذفها مع تأكيد.
- **بطاقة إنفوجرافيك للتقرير اليومي**: اسم المدرسة، التاريخ، نسبة الإنجاز، والمهام مقسمة حسب الفترة مع الأيقونات، مع:
  - **حفظ كصورة PNG** لمشاركتها مع الإدارة.
  - **طباعة / حفظ PDF** من نافذة الطباعة في المتصفح (اختر «حفظ بتنسيق PDF»).

## التشغيل

افتح ملف `index.html` مباشرة في المتصفح، أو استخدم رابط GitHub Pages الخاص بالمستودع. لا يحتاج التطبيق إلى خادم أو تثبيت.

## التقنيات

- HTML + JavaScript في ملف واحد
- Tailwind CSS (عبر CDN)
- أيقونات Lucide
- html2canvas لتحويل البطاقة إلى صورة
- خطا El Messiri و IBM Plex Sans Arabic من Google Fonts

> البيانات محفوظة في متصفح الجهاز فقط؛ مسح بيانات المتصفح يحذفها، وهي لا تنتقل تلقائياً بين الأجهزة.

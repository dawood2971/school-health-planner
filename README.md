# مخطط الصحة المدرسية

لوحة مهام عربية (RTL) بسيطة في ملف واحد لتنظيم مهام عمل الصحة المدرسية اليومية في:

- مدرسة أبو الدرداء للتعليم الأساسي
- مدرسة الإمام سيف بن سلطان للبنين

## المزايا

- **لوحة بثلاثة أعمدة**: مهام اليوم، قيد التنفيذ، منجزة. على الكمبيوتر تظهر جنباً إلى جنب، وعلى الهاتف تصبح أقساماً متتالية.
- **بطاقة لكل مهمة** فيها: العنوان، وصف قصير اختياري، الأولوية (عاجلة / متوسطة / عادية) بلون مميز، تاريخ الاستحقاق (مع تنبيه «متأخرة»)، خانة إتمام، وزرّا التعديل والحذف.
- **الإتمام بنقرة**: تنتقل المهمة فوراً إلى «منجزة» مشطوبة وباهتة، ويتحدث شريط التقدم. إلغاء الإتمام يعيدها إلى عمودها السابق.
- **شريط تقدم مهام اليوم**: يحسب المهام المستحقة اليوم أو المتأخرة، والمهام التي أُنجزت اليوم.
- **خطة الأسبوع**: الأسبوع كاملاً من الأحد إلى السبت، ولكل يوم زر «+» لإضافة مهمة له مباشرة، مع التنقل بين الأسابيع. في نافذة الإضافة شريط بأيام الأسبوع لاختيار اليوم بنقرة، إضافة إلى حقل التاريخ لأي تاريخ آخر. المهام المستقبلية تنتقل تلقائياً إلى «مهام اليوم» في يومها.
- **حذف المهام المنجزة** دفعة واحدة مع رسالة تأكيد.
- **التبديل بين المدرستين**، ولكل مدرسة مهامها المستقلة.
- **إضافة سريعة** لمهام الصحة المدرسية: محاضرة توعوية (مع الصف)، يوم عالمي في الإذاعة، الفحص الشامل (عدة صفوف معاً)، المشاريع الصحية، التحصينات واللقاحات، تنظيم غرفة الصحة.
- **تقرير اليوم (إنفوجرافيك)**: اسم المدرسة، التاريخ، نسبة الإنجاز، والمهام موزعة على الأعمدة الثلاثة، مع **حفظ كصورة PNG** و**طباعة / حفظ PDF**.
- **الحفظ في المتصفح** عبر localStorage، دون قاعدة بيانات أو تسجيل دخول. المهام المحفوظة من الإصدار السابق تُنقل تلقائياً.

## التشغيل

افتح ملف `index.html` مباشرة في المتصفح، أو استخدم رابط GitHub Pages الخاص بالمستودع. لا يحتاج التطبيق إلى خادم أو تثبيت.

## التقنيات

- HTML + JavaScript في ملف واحد
- Tailwind CSS (عبر CDN)
- أيقونات Lucide
- html2canvas لتحويل البطاقة إلى صورة
- خط IBM Plex Sans Arabic من Google Fonts

> البيانات محفوظة في متصفح الجهاز فقط؛ مسح بيانات المتصفح يحذفها، وهي لا تنتقل تلقائياً بين الأجهزة.
